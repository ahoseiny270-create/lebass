📖 راهنمای قالب مُدرا v1.1

این صفحه مخصوص خریدار قالبه — نصب، شخصی‌سازی و اتصال به بک‌اند در ۱۰ دقیقه

۱ شروع سریع (۲ دقیقه)

قالب هیچ بیلدی لازم نداره؛ فقط سرو کن:

cd lebass
python3 -m http.server 8000
# → http://localhost:8000

یا کل پوشه رو روی هاست / GitHub Pages آپلود کن. اگه فایل‌های tpl/ رو ویرایش کردی، بیلد بگیر:

python3 tools/build.py

۲ ساختار فایل‌ها

assets/js/products.js★ مهم‌ترین فایل: محصولات، قیمت‌ها، کدهای تخفیف
assets/js/main.jsموتور قالب: سبد، فیلتر، جستجو، تسویه (دست نزن مگر حرفه‌ای!)
assets/css/style.cssهمه استایل‌ها + متغیرهای رنگ در ابتدای فایل
assets/img/عکس‌ها — با عکس‌های خودت جایگزین کن (۳×۴)
tpl/partials/هدر، فوتر، مودال‌ها (بعدش build.py اجرا کن)

۳ افزودن محصول جدید

توی products.js یه آبجکت مثل این به آرایه اضافه کن:

{
  id: 13, name: 'نام محصول', brand: 'مُدرا',
  cat: 'women', // women | men | shoes | accessory
  price: 1500000, old: 1800000, // old = null یعنی بدون تخفیف
  rating: 4.5, reviews: 10, badge: 'new', // new | hot | sale
  colors: [{ n: 'کرمی', c: '#e3d0ae' }],
  sizes: ['S','M','L','XL'], img: 'assets/img/p13.jpg',
  stock: 20, sold: 0, added: 11,
  tags: ['کلیدواژه'], desc: 'توضیحات…',
  specs: [['جنس','نخ پنبه']]
}

۴ تغییر رنگ، لوگو و اطلاعات

رنگ اصلیمتغیر --accent در خطوط اول style.css (۴ پوسته آماده هم داخل قالب هست)
نام فروشگاهجستجوی «مُدرا» در فایل‌ها و جایگزینی یکجا
تلفن و آدرسtpl/partials/footer.html و tpl/pages/contact.html
کدهای تخفیفآبجکت coupons در ابتدای products.js
سقف ارسال رایگانfreeShip در products.js

۵ اتصال به بک‌اند (وردپرس/لاراول/…)

قالب فرانت‌اند خالصه و با هر بک‌اندی کار می‌کنه. مسیر پیشنهادی:
۱️⃣ به‌جای MODERA_PRODUCTS، از API خودت JSON بگیر و تو همون متغیر بریز — بقیه قالب (سبد، فیلتر، جستجو) بدون تغییر کار می‌کنه.
۲️⃣ سبد خرید الان در localStorage ذخیره می‌شه؛ موقع ثبت سفارش، آرایه cart رو با fetch به سرورت بفرست.
۳️⃣ درگاه پرداخت: دکمه «ثبت سفارش» (#placeOrder در main.js) رو به درگاه‌ت (زرین‌پال/زیبال) وصل کن.

۶ سوالات پرتکرار خریداران

فونت وزیرمتن داخل پوشه assets/fonts هست و کاملاً آفلاین کار می‌کنه؛ بدون نیاز به CDN و بدون افت سرعت.

حتماً! عکس‌های فعلی فقط دمو هستن. عکس‌های خودت رو با همون نام‌ها در assets/img جایگزین کن. نسبت ۳×۴ پیشنهاد می‌شه.

طبق نقشه راه: صفحه مقایسه محصول، حالت تیره (دارک‌مود) و نسخه وردپرس/ووکامرس. خریداران آپدیت‌ها رو رایگان می‌گیرن.
